## React and Next.js documentation

Before implementing or explaining React or Next.js APIs:
- Check the installed versions in package.json.
- For Next.js, read the relevant documentation under
  node_modules/next/dist/docs/ first.
- For React, consult https://react.dev/reference/react.
- If local Next.js docs are insufficient, consult https://nextjs.org/docs.
- Match guidance to the installed version and router.
- Explain what changed, why, and link the relevant documentation.
- If documentation cannot be accessed, say so instead of guessing.
